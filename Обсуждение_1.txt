1) Создание чего угодно без айди, а редактирование ...object, field1: newValue
2) При создании дисциплины возможность добавить количество часов.
3) При создании поток добавить выбор направления обучения (Cypher).
4) Номер семестра для потока и дисциплин.
5) Матанализ может делиться на лекцию, практику, лабараторную, зачет и экзамен. Делаем отдельную страницу для корневой дисциплины и на странице создания дисциплины выбираем корневую дисциплину(обязательно) из списка + указываем тип дисциплины (для всего кроме экзамена и зачета можно указать только группу и препода)
6) Если дисциплина для двух групп (часть потока, а не весь), то в сетке расписания для группы показывается эта дисциплина.
7) Создание проекта расписания:
	- Название
	- Начало/Конец семестра
	- Начало - четная или нечетная неделя
8) Список преподов для дисциплин убрать. Просто выбираем препода для серии занятий
9) Список аудиторий для дисциплин убрать. Одна аудитория = одна серия занятий
